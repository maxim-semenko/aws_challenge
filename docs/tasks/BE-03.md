## Goal

Functions read and write PostgreSQL only via RDS Proxy, over TLS, without a password in env vars.

## Scope

**In scope**

- Load DB credentials from Secrets Manager at init (cached, refreshed after SnapStart restore)
- JDBC URL to the proxy with `sslmode=require`
- Hikari sizing for Lambda (max 2, min idle 0)

**Out of scope**

- IAM auth (INF-09)

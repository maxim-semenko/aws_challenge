## Goal

Lambda code knows who calls it, based only on claims validated by API Gateway.

## Scope

**In scope**

- Read JWT claims from `requestContext.authorizer.jwt.claims` (access token: `sub`, `cognito:groups`, `client_id`)
- `CurrentUser` and admin check (401/403)
- `local` profile dev user
- `GET /api/me`

**Out of scope**

- Token validation in Lambda (done by API Gateway)

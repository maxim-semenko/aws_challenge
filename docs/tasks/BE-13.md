## Goal

The `admin` function proves the path Lambda → RDS Proxy → PostgreSQL works: it runs `SELECT 1` and returns the result.

## Scope

**In scope**

- Handler code for the Week 1 functions `admin`, `chatbot`, `sync` in the form decided by Q-10
- `admin`: read DB credentials from Secrets Manager, connect to the **proxy** endpoint with TLS, run `SELECT 1`,
  return `{"result":1,"durationMs":…}`
- One structured log line per invocation (no credentials, no connection string with password)
- Unit test for the handler logic that does not need AWS

**Out of scope**

- Spring datasource, Hikari tuning, SnapStart restore hooks (BE-03, BE-12)
- Flyway / schema (BE-05, DB-01)
